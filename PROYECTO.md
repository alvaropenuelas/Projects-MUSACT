# PROYECTO — Crusader’s Chronicle

## Descripción
Crusader’s Chronicle es un modpack RPG cooperativo para Minecraft 1.20.1 con Forge.
Incluye mods propios, KubeJS, datapacks, recursos y una campaña narrativa.

## Estructura del proyecto
- `./instancia`: instancia completa del modpack.
- `./fuentes`: proyectos fuente disponibles.
- `./trabajo`: extracciones, código descompilado y cambios preparados.
- `./docs`: documentación, encargos e historial.
- `./.claude/skills/modpack`: skill del proyecto.
